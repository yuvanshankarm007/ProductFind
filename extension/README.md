# ProductFind Sentinel — Browser Extension (Manifest V3)

Autonomous real-time eCommerce arbitration, PayPal Section 13 protection, and Knapsack basket optimization directly on Amazon, Flipkart, Best Buy, and OEM stores.

## 🚀 How to Install in Chrome / Brave / Edge (2 Steps)

1. Open **`chrome://extensions`** (or **`brave://extensions`** / **`edge://extensions`**) in your browser.
2. Enable **Developer mode** (toggle in top-right corner).
3. Click **"Load unpacked"** and select this directory:
   ```
   C:\Users\yuvan\.gemini\antigravity\scratch\ProductFind\extension
   ```

## ⚡ What it Does
- **Automatic Deal Arbitration**: When browsing Amazon or Flipkart, Sentinel detects the product in your active tab and displays an arbitrated price comparison.
- **Injected Floating Pill**: Injects a clean pill badge in the corner of retailer pages: *"Sentinel found this ₹3,200 cheaper on OEM Direct"*.
- **1-Click Cockpit**: Opens the full ProductFind Sentinel cockpit with 1 click.
- **Price Drop Watchdog**: Allows you to subscribe to price drops directly from any product page.
